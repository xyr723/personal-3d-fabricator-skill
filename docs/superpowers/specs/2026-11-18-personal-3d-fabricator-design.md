# Personal 3D Fabricator Skill 设计规格

日期：2026-11-18  
目标版本：v0.1.0

## 1. 目标

创建一个可在 Windows、macOS 和 Linux 使用的 Codex Skill，把家用功能件和自用道具需求转化为可编辑、可检查、可拆分、可装配的 3D 打印项目。

本项目不重复切片器或打印机官方软件已有的设备控制能力。核心价值是需求理解、参数化建模、现有模型改造、超尺寸模型拆分、连接结构设计、设备能力适配、版本记录和装配交付。

仓库名称为 `personal-3d-fabricator-skill`，Skill 名称为 `personal-3d-fabricator`。仓库计划公开发布到 `xyr723/personal-3d-fabricator-skill`，采用 MIT 许可证。

## 2. 首期范围

### 2.1 包含

- 接收中文自然语言、照片、草图、关键尺寸及 STL、OBJ、3MF、STEP 模型。
- 从尺寸和草图创建参数化家用功能件。
- 根据多角度参考图规划道具结构，并生成可继续编辑的 CadQuery 或 Blender 工程。
- 检查并改造已有模型，包括缩放、挖空、加厚、开孔、安装座、卡扣、磁铁孔等常用操作。
- 按目标打印机成型空间拆分大模型，设计定位销、榫槽、磁吸或螺丝连接。
- 生成零件编号、多盘分组、装配说明、物料清单、检查报告和版本记录。
- 提供通用单喷嘴、通用双喷嘴能力模板，并以 X2D 作为首个验证过的具体设备配置。
- 在 Windows、macOS 和 Linux 上运行核心工作流和测试。

### 2.2 不包含

- 从单张照片精确重建任意复杂三维物体。
- 接入收费的图片转 3D 云服务。
- 光固化树脂打印流程。
- 自建三维编辑器或桌面 GUI。
- 自动操作切片器界面、远程加热或启动打印。
- 对承重、防护、儿童用品、食品接触、电气绝缘或高温部件作安全认证。

## 3. 设计原则

- 一个可安装 Skill、三个内部工作流，避免多个 Skill 的安装和维护负担。
- AI 负责理解需求、选择策略和生成可编辑建模步骤；确定性脚本负责几何计算、配置校验和结果验收。
- 原始输入只读保存；所有修改生成新版本，不覆盖原文件。
- 不猜测绝对尺寸。无比例基准或关键装配尺寸时停止并请求补充。
- 按设备能力决策，不在核心逻辑中硬编码品牌或型号。
- 缺少可选工具时只禁用相关工作流，不让整个 Skill 失效。
- 在整体设计和拆分方案处设置两个人工确认门。

## 5. 工作流

### 5.1 从零创建

1. 收集用途、参考图、关键尺寸、材料和装配约束。
2. 判断任务属于参数化功能件还是外观道具。
3. 功能件优先使用 CadQuery；复杂网格或曲面道具使用 Blender。
4. 生成整体模型、尺寸摘要和预览。
5. 进入第一次人工确认。
6. 确认后进入设备适配、拆分和连接结构设计。

参考图只能辅助外形和比例判断。涉及装配时必须提供孔距、安装面或至少一个可信的比例基准。复杂人物、雕塑和高度艺术化曲面允许生成基础工程，但不承诺一键精准复刻。

### 5.2 已有模型改造

1. 复制原始文件到项目 `source/`，记录哈希和格式。
2. 检查单位、包围盒、封闭性、法线、破面、薄壁和独立壳体。
3. 判断直接修改网格还是重建参数化实体。
4. 生成新版本和改造前后差异报告。
5. 输出整体预览并进入第一次人工确认。

### 5.3 大模型拆分

1. 读取打印机能力配置和当前模型尺寸。
2. 根据外观焦点、受力方向、打印方向和装配可达性生成候选切割方案。
3. 避免在主要受力区和显眼外观面设置切割线。
4. 为候选方案生成定位销、榫槽、磁吸或螺丝连接。
5. 检查配对关系、装配间隙、碰撞和各零件成型空间适配。
6. 生成拆件预览、多盘分组和装配顺序。
7. 进入第二次人工确认，确认后才输出正式打印文件。

## 6. 输入与输出

每个制作任务使用独立项目目录：

```text
project-name/
├── source/
├── editable/
├── printable/
├── previews/
├── versions/
├── project.json
├── print-plan.json
├── inspection.json
└── assembly.md
```

`project.json` 记录需求、单位、尺寸基准、材料、设备配置、当前阶段和确认状态。`print-plan.json` 记录零件、方向、连接方式、多盘分组和估算所需信息。`inspection.json` 使用结构化问题代码和严重级别，便于脚本和 Skill 一致处理。

正式输出至少包含：

- 可编辑源文件：STEP、CadQuery Python 或 Blender 工程。
- 可打印文件：按零件编号的 STL，必要时提供通用 3MF。
- 整体与拆件预览图。
- 几何检查报告、设备适配结果和装配说明。

切片器专有项目由可选适配器生成，不作为核心交付的必要条件。

## 7. 设备能力层

核心代码仅依赖能力字段，例如：

```json
{
  "build_volume_mm": [256, 256, 256],
  "toolhead_count": 2,
  "nozzle_diameters_mm": [0.4],
  "enclosed": true,
  "heated_chamber": true,
  "supported_materials": ["PLA", "PETG", "ABS"],
  "slicer": "bambu-studio"
}
```

品牌机型配置继承通用模板并允许用户本地覆盖。配置中的官方参数应记录来源和核验日期。未知字段不得自动推断为支持；缺失能力应触发保守方案或请求用户确认。

## 8. 技术选型

- Python：跨平台脚本、项目状态和配置校验。
- trimesh：网格读取、尺寸、封闭性、切割和碰撞检查。
- CadQuery：参数化功能件和规则化连接结构。
- Blender Python：复杂网格、道具外形、模型修整和预览渲染。
- Pydantic：项目清单、设备配置和报告的运行时校验，并导出 JSON Schema 供外部工具使用。

核心依赖与可选重型依赖分组安装。外部程序通过系统 `PATH`、常见安装位置和用户配置依次探测；不得硬编码单一操作系统路径。进程调用使用参数数组，不拼接 Shell 命令。

## 9. 错误处理与安全边界

- 几何操作失败时保留上一版本、中间结果和诊断信息。
- 修复后必须重新执行封闭性、尺寸和成型空间检查。
- 无法可靠生成连接结构时，输出候选切割面但不伪造可装配结论。
- 涉及高风险用途时标记风险、降低自动化程度并要求专业验证。
- Skill 不保存打印机密钥，不修改全局应用配置，不直接启动打印。
- 所有路径和配置必须支持 Windows、macOS 与 Linux，不把个人目录提交到 GitHub。

## 10. 测试与验收

GitHub Actions 使用 Windows、macOS、Linux 测试矩阵。核心验收包括：

- Skill frontmatter、目录结构和引用完整性。
- 项目清单、设备配置和检查报告的 Schema 校验。
- STL、OBJ、3MF 和 STEP 的最小读取或适配器烟雾测试。
- 包围盒、单位、封闭性、薄壁和独立壳体检测。
- 拆分后体积或网格覆盖关系保持在允许误差内。
- 定位销与配对孔数量、方向和配置间隙一致。
- 每个拆分件均能放入目标成型空间。
- 同一测试夹具在三平台产生一致的关键几何指标。
- CadQuery 和 Blender 可选适配器的安装检测与最小执行测试。

发布 v0.1.0 前还需用一个参数化家用支架和一个超尺寸道具模型完成端到端验收，包括两次人工确认和最终装配文档。

## 11. 发布方式

完成实现和验证后：

1. 初始化 Git 仓库并提交已验证内容。
2. 重新授权当前失效的 GitHub CLI 登录。
3. 创建公开仓库 `xyr723/personal-3d-fabricator-skill`。
4. 推送默认分支并检查三平台 GitHub Actions。
5. 所有检查通过后创建 `v0.1.0` Release。

不得提交用户模型、参考图、打印记录、机器地址、令牌或其他个人数据。

## 12. 成功标准

- 用户能够在三种桌面操作系统上安装并触发 Skill。
- Skill 能正确路由从零建模、已有模型改造和超尺寸拆分三类请求。
- 核心几何结论由可重复脚本验证，而不是仅依赖语言模型判断。
- 设备差异通过能力配置处理，新增机型不要求修改核心工作流。
- 两个人工确认门能阻止未经确认的整体模型或拆分方案进入下一阶段。
- 输出包含可编辑源文件、可打印分件、检查报告和可执行的装配说明。
