# 拆分大型模型

1. 读取项目的可信比例、整体尺寸和打印机成型空间。展示带尺寸的整体预览，确认用户接受外形、比例和装配基准。取得明确同意后，用项目审批接口将状态从 `draft` 推进到 `overall_approved`。此状态是执行拆件的前置条件。
2. 比较候选切割面，考虑可见接缝、主要受力方向、打印朝向和装配可达性。选择平切或一体定位销，检查公差、配对关系、零件相交和每个零件在选定朝向下的成型空间。
3. 向用户展示编号零件、接缝与连接件位置、建议摆放、分盘和装配顺序。提交预览后等待用户明确同意该方案，再将状态从 `overall_approved` 推进到 `split_approved`。
4. 读取并验证项目中持久化的 `split_approved` 后，生成编号打印文件、可编辑模型和装配说明。整理每件的尺寸、打印方向、配套硬件和几何检查结果。
5. 交付前核对预览对应的模型文件和方案参数。已经批准的整体几何、比例或拆分方案发生变化时，为修订建立新的 `draft` 项目，重新完成两次确认。

## CLI 拆件参数

`plan-split` 沿超限轴等距切割，并对仍超限的子件继续切割。编号按切割轴从小到大递归生成。每轴预留 2 mm 成型余量。检查导出 STL 的水密性、尺寸、位置和体积，平切拆件总体积的相对容差为 0.01%。

- `--connector flat` 使用平切面，也是默认值。
- `--connector pin --pin-diameter-mm 4 --pin-length-mm 6 --pin-clearance-mm 0.2` 使用 CadQuery 在相邻零件之间生成一体定位销与等深盲孔。示例数值也是默认值，单位为毫米；间隙是半径差，孔径等于销径加两倍间隙。按打印机、材料和试片结果选择间隙。
- 每对相邻件的共同切面布置一个销孔对。切面包含多个分离材料区域时，应分别处理各实体或选平切。销径至少为配置中最小喷嘴直径的两倍。销从较小坐标一侧沿切割轴正方向伸出。程序用设备配置中的最大喷嘴直径检查孔侧和孔底剩余材料。切面过窄、孔深处壁面受阻、带销件超出成型空间时，规划会停止。可在保存拆件预览前调整参数或改选平切。磁铁孔和嵌件孔目前仅有建模 API。
- 查看拆件爆炸图和参数摘要。STL 与装配坐标相同，爆炸图的分隔只用于查看接缝。已保存的拆件预览会冻结销孔参数，修改已记录的选择时需重新建立修订项目。交付说明列出配对件、位置、插入方向和试装步骤。

审批和交付带销方案时，核心环境会从批准源重建接缝，核对编号 STL 中销壁、孔壁、端面和连接边环。旧方案若只连接分离截面中的一处，须在修订项目中分别处理实体或改选平切。
