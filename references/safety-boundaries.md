# 安全边界

先记录用途、安装条件、接触对象和使用环境。用途无法判断且可能涉及以下风险时，先确认用途。遇到安全关键需求时，将本工作流限于外观样件、尺寸验证或供具备相关资质的专业人员审核的设计资料。正式使用涉及材料、工艺、整件验证和适用规范时，由负责该用途的专业人员评估。几何检查和用户审批仅覆盖本项目的模型及设计方案，不能作为认证。

| 用途 | 需要评估的失效方式 |
| --- | --- |
| 承重或悬挂 | 层间开裂、接头脱落、长期蠕变、冲击和循环载荷 |
| 防护 | 冲击、飞溅或高压作用下破裂，以及失效后对人的暴露 |
| 儿童用品 | 小件脱落、误吞、夹伤、锐边、材料暴露 |
| 食品接触 | 原料与添加剂、设备污染、层纹积污、清洗与温度耐受性 |
| 电气 | 绝缘失效、爬电或电气间隙不足、起火，以及外壳受热变形 |
| 高温 | 软化、变形、分解及材料随时间和热循环劣化 |

在预览和交付说明上标注样件用途及待验证事项。切片与打印由用户在其设备上检查后操作。
