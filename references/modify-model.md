# 修改已有模型

1. 使用 CLI 的 `inspect --project` 流程或库函数 `record_artifact`，将原件归档到项目的 `source/`。省略输入路径时，草稿从 `project.json` 的归档记录中选择唯一已登记的网格，并核对文件大小及 SHA-256。旧草稿只迁移有整体预览或批准记录且校验一致的原件。只有散放文件时，请从保留的外部原件重新导入。对已有模型先确认单位、修改区域、关键尺寸与需保留的装配界面。STL 或 OBJ 缺少可信尺寸基准时，请用户确认单位和至少一项已知尺寸。
2. 按源文件类型选路线。
   - STL、OBJ 和网格 3MF 优先保留原网格。用网格检查定位独立壳体、开口、退化面和法线异常。形状调整和局部网格修整使用 Blender，修复后复测尺寸和完整性。
   - STEP 优先用 CadQuery 的 STEP 适配器读入，并以实体几何编辑。若提供了原始参数模型，优先修改其参数。仅有网格却需要精确加工特征时，依据可信的测量值重建相关实体，核对与原模型的偏差和装配基准。
3. 在 `editable/` 或 `versions/` 保存新版本和可编辑源文件。保留归档原件，使用新文件名写入修改产物。在草稿项目中运行 `personal-3d-fabricator inspect 项目/editable/修订.stl --project 项目 --assumed-unit mm` 可归档此次修订并生成整体预览。命令中的单位应与文件实际单位一致。已有审批记录时先建立新的草稿项目。
4. 提供同视角的前后预览，列出变更尺寸、几何检查结果和装配影响。需要拆件时，用修改后的模型开始[拆分大型模型](split-large-model.md)的两步确认。
